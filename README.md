# Servicerized
Provide or rent services as much as you want.

[English](README.md) | [Português do Brasil](README.pt-BR.md)

## Introduction

Servicerized is an API that lets you rent services from all places in the world. It allows you to **list products** and find whatever you like by **filtering by categories**, name, price etc.

Additionally, the API comes with a **robust payment system integration** to let you pay whoever you like.
```NOT_IMPLEMENTED```

If you're indecise at the moment of purchase, there is also a **shopping cart feature** where you can **store your wanted services** for later.
```NOT_IMPLEMENTED```

Servicerized is also transparent, you can always **see information about your orders**. Not only that but **you can cancel them and get refunded on time**.
```NOT_IMPLEMENTED```

Also, don't worry about forgetting your orders, the API contains a nice **notification system** that e-mails you about the status of your purchases.
```NOT_IMPLEMENTED```

Still, if you don't want to rent any services, **you can also provide them** to get some pennies, by **creating an account** you can create your own products and manage them.

For more information about providing services check [Service Providers](./documentation/service-providers.md).

The API is fully secured by a **strong authentication system** that handles user authorization with fine grain control.
