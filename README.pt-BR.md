# Servicerized
Preste ou alugue serviços o quanto quiser.

[Pt-BR](README.pt-BR.md) | [En-US](README.md)

## Introdução

O Servicerized é uma API que permite alugar serviços de qualquer lugar do mundo. Ela permite que você **liste produtos** e encontre o que quiser **filtrando por categorias**, nome, preço, etc.

Além disso, a API conta com uma **integração com sistema de pagamento robusto** para que você possa pagar a quem quiser.
```NOT_IMPLEMENTED```

Se você estiver indeciso no momento da compra, também há um **recurso de carrinho de compras** onde você pode **salvar os serviços desejados** para mais tarde.
```NOT_IMPLEMENTED```

O Servicerized também é transparente: você sempre pode **ver informações sobre seus pedidos**. Além disso, **você pode cancelá-los e receber o reembolso a tempo**.
```NOT_IMPLEMENTED```

E não se preocupe em esquecer seus pedidos, a API contém um ótimo **sistema de notificações** que envia e-mails sobre o status das suas compras.
```NOT_IMPLEMENTED```

Mesmo assim, se você não quiser alugar nenhum serviço, **você também pode prestá-los** para ganhar uma renda extra. Ao **criar uma conta**, você pode criar e gerenciar seus próprios produtos.

Para mais informações sobre a prestação de serviços, consulte [Provedores de Serviço](./documentation/service-providers.md).

A API é totalmente protegida por um **sistema de autenticação forte** que lida com a autorização de usuários de forma detalhada e precisa.
