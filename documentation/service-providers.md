# Introduction to service providing

Any user registered in the API can apply one of its groups as a service provider. A service provider is a user managed group who can manage and display rentable services.

## Smart Order limits

Since providing a service takes time service providers can only take as many orders as their number of contributors allow. 

This measure prevents exceding provision capacity and guarantees that service providers can always complete their orders.

Each contributor can only take at maximum 14 hours of work for each day. 

If the amount of hours for all rented orders surpasses ```contributor availability hours * contributors amount``` hours, the API disables renting services until there is available time.

**You can always edit the amount of time a service takes to complete!**
