## Deployment

This service requires the following dependencies:
- A Postgres database: Whose connection information must be defined at [Configuration](../src/main/resources/application.yml). More about the database can be found [Here](./database.md).
- A mailer service: Whose conection information must defined at [Configuration](../src/main/resources/application.yml).
